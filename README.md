# MacroRec

Десктопный рекордер макросов: записывает движения мыши и нажатия клавиш и воспроизводит их в человеческом темпе — с естественным разбросом таймингов, а не ровным механическим шагом.

Нужен там, где у системы нет API — только графический интерфейс, с которым приходится работать руками. Python, около 1 400 строк.

## Зачем разброс таймингов

Воспроизведение «клик ровно каждые 200 мс» ломается на интерфейсах, которые ждут человеческого темпа (анимации, подгрузка, проверка ввода). `Player` накладывает на записанные тайминги гауссово дрожание (`random.gauss`) вместо фиксированных интервалов — плюс регулируемый общий множитель скорости (0.5×–2×) на воспроизведение. Ничего сверхъестественного, но заметно ближе к тому, как работает человек, чем воспроизведение один в один.

## Что умеет

- Запись мыши (клики, движение) и клавиатуры глобальным хоткеем (по умолчанию F9, настраивается)
- Таймлайн записанных событий с человекочитаемым описанием каждого шага (`_humanize_events`) — видно, что именно записалось, до воспроизведения
- Воспроизведение с выбором скорости и обратным отсчётом перед стартом
- Сохранение/загрузка макросов в JSON — можно редактировать руками или генерировать программно
- Тёмный UI на CustomTkinter, конфиг между запусками — в `~/.macrorec/config.json`

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

## Сборка в exe

```bash
build.bat
```

PyInstaller-спека — `MacroRec.spec`.

## Стек

Python, `pynput` (глобальный перехват ввода), `customtkinter` (UI), `PyInstaller` (дистрибутив под Windows).

## Где используется

Как движок движения курсора в [AI Vision](https://github.com/LDRION/ai-vision) — computer-use агенте, который видит экран и работает мышью: каждое действие агента сохраняется в формате `.rec` и открывается в редакторе MacroRec.
