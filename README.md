# MacroRec

Десктопный рекордер макросов: записывает движения мыши и нажатия клавиш, воспроизводит с рандомизацией таймингов, чтобы это не выглядело как ровный бездушный скрипт.

Сделан как замена n8n/PhantomBuster-подходу там, где у целевой системы просто нет API — только GUI, с которым надо взаимодействовать руками (или почти руками).

## Зачем нужна рандомизация

Тупой replay «клик каждые 200мс» палится любой минимально внимательной системой. `Player` накладывает на записанные тайминги гауссово дрожание (`random.gauss`) вместо фиксированных интервалов — плюс регулируемый общий множитель скорости (0.5×–2×) на воспроизведение. Ничего сверхъестественного, но заметно ближе к тому, как двигается человек, чем raw-replay один в один.

## Что умеет

- Запись мыши (клики, движение) и клавиатуры глобальным хоткеем (по умолчанию F9, настраивается)
- Таймлайн записанных событий с человекочитаемым описанием каждого шага (`_humanize_events`) — видно, что именно записалось, до воспроизведения
- Воспроизведение с выбором скорости и обратным отсчётом перед стартом
- Сохранение/загрузка макросов в JSON — можно редактировать руками или генерировать программно
- Тёмный UI на CustomTkinter, конфиг между запусками — в `~/.macrorec/config.json`

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

## Сборка в exe

```bash
build.bat
```

PyInstaller-спека — `MacroRec.spec`.

## Стек

Python, `pynput` (глобальный перехват ввода), `customtkinter` (UI), `PyInstaller` (дистрибутив под Windows).

## Где используется

Как движок автоматизации внутри [NVC](https://github.com/LDRION/nvc-showcase) — там NVC поднимает несколько параллельных песочниц, а MacroRec в каждой воспроизводит записанный сценарий действий.
